# 【育儿宝典】想让宝贝更聪明，新手爸妈学起来

> 更新时间：2026-09-16 (UTC+8)

点击上方蓝字关注我们

**从孩子降临世上的那一刻起，恭喜你们成为了爸爸妈妈。**
这是一个全新的生命，也是一个全新的开始。**“第一次做父母，怎么做才能带好孩子呢？”**想让宝宝变得聪明优秀，赢在起跑线，新手爸妈，快收下这份训练指南。

**爸爸妈妈，请多指教**
**1-3个月宝贝训练****0****1**
**视觉训练**
1. 在宝贝安静觉醒状态下进行，仰卧于床面                
2. 使用黑白卡、彩色卡、直径10cm的红球
3. 放于距离宝贝眼睛上方20cm处
4. 宝贝注视后，向两侧弧形移动
5. 每天1-2次，每次20秒并逐渐增加至1-2分钟
6. 3个月时能180度追视

**0****2**
**听觉训练**
1. 宝贝仰卧在床面
2. 使用摇铃等不同声响的玩具
3. 距离宝贝耳朵20cm处摇动，两只耳朵轮流进行
4. 每天1-2次，每次1-2分钟
5. 4个月时能转头寻声源

**0****3**
**视听结合训练**
1. 家长与宝贝对视，距离20cm
2. 声音温柔、表情丰富
3. 呼唤宝贝，从中线向左右180度缓慢移动
4. 每天1-2次，每次1-2分钟
5. 3个月宝贝能笑着追看家长的脸

**0****4**
**触觉训练**
1. 将手指、细柄摇铃、拨浪鼓、积木、毛绒玩具、抚触球等放于宝贝手中2. 注意：物品需无毒、大小合适、保证安全
3. 可使用抚触球接触宝宝皮肤，在宝贝身上进行滚动
4. 3个月时能抓握半分钟

**0****5**
**俯卧抬头训练**
1. 喂奶至少半小时后进行
2. 宝贝俯卧至平整床面，两手撑至胸前
3. 注意观察宝贝呼吸，勿使宝贝口鼻贴于床面
4. 用玩具逗引宝贝抬头
5. 每次1-2分钟逐渐至能抬头更长时间
6. 4个月时宝贝能抬头90度，左右转头180度

**0****6**
**平衡训练**
1. 双手托住头肩部与臀部
2. 宝贝呈45度倾斜位，慢慢左右移动
3. 移动时，微笑注视宝贝，唱儿歌
4. 摇摆时注意安全，速度不要太快
5. 一次1-2分钟，一天1-2次

出生一个月后，可每天坚持做被动操。
被动操不仅能增强宝宝身体各部动作的协调力，还能促进体力和智力的发展。

**爸爸妈妈**

**该帮宝贝做操啦！**
**被 动 操**
**第一节 上肢运****动**

1．预备姿势：婴儿仰卧，母亲大拇指放在宝贝掌心，轻握宝贝双腕，婴儿两臂放在身体两侧2．两臂左右伸直平举，掌心向上3．两臂前伸，掌心相对4．两臂上举至头两侧，掌心向上5．还原

**第二节 肘部运动**

1．预备姿势2．弯曲宝贝肘部，触肩，左右手臂轮流进行3．还原

**第三节 扩胸运动**

1．预备姿势2．两臂左右伸直平举3．左右手臂上下交替抱胸4．还原

**第四节 上肢放松运动**

1．两臂交替上举与床面呈45°2．还原

**第五节 下肢运动**

1．预备姿势：宝贝仰卧两腿伸直2．妈妈轻握宝贝脚腕，将宝贝两腿同时屈曲至腹部3．妈妈让宝贝两腿轮流屈曲至腹部

**第六节 两下肢伸直上举**

1．预备姿势：宝贝仰卧两腿伸直

2．妈妈双手轻握宝贝双膝

3．让宝贝双腿上举与躯干呈直角

**第七节 下肢放松运动**

1．放松两腿与床面呈45°

2．还原

**被动操小贴士**

- 
于喂奶结束至少半小时后进行

- 
穿轻薄单衣，放于平整床面

- 
四肢伸直，可配合抚触放松后进行

- 
做操时可放音乐、与宝贝聊天说话、对视

- 
一天4-5次，可做至6个月

- 
每节体操4x4拍

除了被动操，婴儿抚触操也是儿科医生建议爸爸妈妈可以经常给小宝宝做的保健操，不仅可以增进与宝宝的感情，也有利于宝宝进行全身放松。

**爸爸妈妈**要多抚摸宝贝喔！
**第一节 面颊抚摸**

从前额中心眉上方轻柔地向太阳穴方向平推；从下巴沿脸轮廓向耳垂方向平推。“小脸蛋，真可爱，妈妈摸摸更可爱”

**第二节 摸捏耳垂**

妈妈的拇指和食指轻拉宝贝耳朵，反复向下轻轻拉扯，不断揉捏。

“小耳朵，拉一拉，妈妈说话宝宝乐”

**第三节 胸部抚触**

双手放于宝贝两侧肋缘，右手向上滑向左肩，左手滑向右肩，交替进行。

“摸摸胸口，真勇敢，宝贝长大最能干”

**第四节 腹部抚触**

妈妈放平手掌，顺时针方向抚摸宝贝上腹部，注意避开肚脐和下腹部位置。

“小肚皮，软绵绵，宝贝笑得甜又甜”

**第五节 手臂抚触**

妈妈轻捏宝贝手臂，从上臂到手腕。

“妈妈搓搓小手臂，宝贝长大有力气”

**第六节 腿部抚触**

妈妈用拇指、食指和中指轻柔宝贝大腿肌肉；妈妈一手握住宝贝脚后跟，另一只手握住宝贝小腿捏压。“宝贝会跑又会跳，爸爸妈妈乐陶陶”

**第七节 脚掌抚触**

妈妈用大拇指指肚顺时针方向轻揉宝贝脚底。

“妈妈给你揉揉脚，宝贝健康身体好”

**第八节 背部抚触**

妈妈拇指指腹从背部中央向两侧抚摸，从肩部移到尾椎。

“妈妈给你怕拍背，宝贝背直不怕累”

**抚触小贴士**

- 
宝贝沐浴后，身上盖干燥浴巾，仰卧床上进行最佳

- 
冬日可开暖气，注意保暖

- 
家长应修剪指甲、手掌抹婴儿油，接触宝贝皮肤按摩

- 
抚触时与宝宝对视、说话

- 
每日至少1次，3个月时宝宝肢体放松

  

爸爸妈妈们，快跟着小编一起做起来！
