# 孕期乳头分泌物多、结痂是怎么回事？

> 更新时间：2026-09-11 (UTC+8)

**正常生理现象。**

女性怀孕之后，体内会分泌大量的雌激素、孕激素，连同催乳素、人胎盘生乳素等激素共同刺激乳腺发育，导致乳头皮脂腺分泌过多，继而可能出现角质层堆积。这种情况下，孕妈妈可能会看到乳头结痂，痂的颜色与乳头一致（偏黑）[1]。

随着孕周的进展，孕妈妈的乳腺充分发育，为分娩后的哺乳做准备。

在孕中期（14 周 ≤ 孕周 28 周），孕妈妈的乳房就开始产奶了。待接近预产期的时候，稍微受到挤压，乳头就会溢出少量淡黄色、水样液体，即初乳。如果未及时擦拭、清洗干净，初乳干燥后，可在乳头处形成痂。此类现象一般发生于两侧乳头[1-3]。

上述情况均属于正常的生理现象，孕妈妈不用过分担心，如无其他不适，注意乳房清洁（如用干净柔软的毛巾蘸清水轻轻擦拭）、定期做好产检就行。
